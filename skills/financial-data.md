# 财务数据获取与交叉验证规范

本规范适用于所有涉及企业财务数据的研究。**每个关键数据必须来自两个独立来源，误差>1%须标记。**

---

## 第零层：MCP 数据连接器（优先于网页抓取）

仓库根目录 `.mcp.json` 已接入三个免费 MCP 数据服务器。**当这些工具在会话中可用时，
优先调用它们取数，网页搜索/抓取降级为备用与交叉验证通道**——MCP 返回的是结构化数据，
比网页抓取更稳定、更省 token、更不易解析出错。

| 服务器 | 覆盖 | 说明 |
|--------|------|------|
| `yahoo-finance` | 实时行情、历史价格、财务报表、分析师评级 | 免费无需 API key |
| `sec-edgar` | 10-K / 10-Q / 8-K 原文、XBRL 财务事实、全文检索 | 免费无需 API key，美股一手数据首选 |
| `fred` | GDP / 通胀 / 失业率 / 利率等 80 万+ 宏观序列 | 需免费 `FRED_API_KEY` 环境变量（fred.stlouisfed.org 注册） |

**交叉验证规则不变**：即使数据来自 MCP，关键数据仍须第二个独立来源（下方网页来源
即为第二来源）；A 股继续使用 `tools/ashare_data.py` + 下表来源，不经 MCP。

MCP 工具不可用时（未安装依赖 / npx 失败），直接按下方网页来源执行，流程不受影响。

## 执行规范

### 第一步：获取数据

对每个财务指标（收入、净利润、毛利率、经营现金流、资产负债率等），分别从**来源1**和**来源2**取数。

### 第二步：误差计算与标记

```
误差率 = |来源1数值 - 来源2数值| / 来源1数值 × 100%
```

| 误差 | 处理方式 |
|------|---------|
| ≤ 1% | ✅ 一致，取来源1数值，标注两个来源 |
| 1% ~ 5% | ⚠️ 标记"数据存在差异"，注明两个数值，说明可能原因（汇率/会计口径） |
| > 5% | ❌ 标记"数据存在重大差异"，必须查原始财报核实，不得直接使用 |

### 第三步：数据呈现格式

每个关键数据必须按以下格式标注：

```
收入：1,239亿元 ✅
  - macrotrends: 1,241亿元
  - stockanalysis: 1,237亿元
  - 误差: 0.3%
```

差异示例：
```
净利润：245亿元 ⚠️ 数据存在差异
  - macrotrends: 245亿元（GAAP）
  - stockanalysis: 278亿元（Non-GAAP）
  - 误差: 13.5% — 原因：会计口径不同（GAAP vs Non-GAAP）
```

---

## 常见差异原因（不一定是数据错误）

| 原因 | 说明 |
|------|------|
| GAAP vs Non-GAAP | 最常见，尤其是利润类数据 |
| 汇率换算 | 港币/人民币/美元换算时间点不同 |
| 财年定义 | 自然年 vs 财年（如苹果财年10月结束） |
| 合并口径 | 是否含少数股东权益 |
| 数据更新滞后 | 某平台尚未更新最新一期财报 |

---

## 特别规则

1. **未上市公司**（米哈游、莉莉丝等）：只有一手数据来源时，数据前标记 `[估计]`，不执行交叉验证
2. **季度数据 vs 年度数据**：优先使用年度数据做交叉验证，季度数据部分来源可能有滞后
3. **原始财报优先**：若两个来源均与原始财报（10-K/年报PDF）不符，以原始财报为准，标记来源错误
